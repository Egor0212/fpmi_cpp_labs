# Лабораторная работа №4. Двумерные массивы

В рамках данной лабораторной работы вам предстоит поработать с двумерными массивами в C++. Текст с заданием находится в файле [task_lab4.md](./task_lab4.md).

При решении данной лабораторной работы **запрещается** использовать `std::vector`, `std::array` и подобные классы из стандартной библиотеки!!!

**Номер варианта**: $(N - 1) \mod13 + 1$, где $N$ – ваш порядковый номер в подгруппе.
