В данной работе вам предстоит реализовать такую структуру данных как односвязный список (**forward list**), а также написать для него итератор (**forward iterator**).

> В данной лабораторной работе **запрещено** использовать классы `list` и `forward_list` из стандартной библиотеки!!!

Текст с заданием находится в файле [task_rgr1.md](./task_rgr1.md)
