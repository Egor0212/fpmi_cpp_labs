# Лабораторная работа №6. Работа с файлами. Файловые потоки

Входной текстовый файл `input.txt` состоит из строк соответствующего варианта [лабораторной работы №5](../lab5_strings/task_lab5.md). Для каждой строки входного файла выполнить действие, описанное в задании соответствующего варианта. Для вариантов 3 и 12 задания будут отличаться (см. задания ниже). Результат выполнения записать в соответствующую строку выходного файла `output.txt`.

Также создать ещё один файл `log.txt`, в котором записывать (логгировать) всё, что происходит во время выполнения вашей программы.

### Вариант 3
Каждая строка текстового файла `input.txt` содержит 5 попыток пользователя ввести номер свеого мобильного телефона (разделенных символом `;`). Из этих номеров выбрать валидные (которые соответствуют формату белорусского номера: `+375 (25/29/33/44) XXX-XX-XX`) и записать их в соответствующей строке выходного файла `output.txt`. Если все 5 номеров окажутся невалидными, то в соответствующей строке выходного файла написать `no valid numbers`.

### Вариант 12
Каждая строка входного текстового файла `input.txt` представляет собой email-адрес. В первой строке выходного файла `valid_emails.txt` записать количество валидных email-адресов, а в последующих строках — сами email-адреса. Аналогичную информацию о невалидных email-адресах записать в файл `invalid_emails.txt`. Email-адрес будем считать **валидным**, если:
1. В строке ровно один символ `@`.
2. Часть до `@` (имя пользователя):
   - Не пустая.
   - Содержит только латинские буквы (`a–z, A–Z`), цифры (`0–9`), точки `.`, подчёркивания `_`, дефисы `-`.
   - Не начинается и не заканчивается точкой.
   - Не содержит двух точек подряд (`..`).
3. Часть после `@` (домен):
   - Не пустая.
   - Содержит хотя бы одну точку (`.`).
   - Каждая часть между точками (например, _example_, _com_ в `example.com`) состоит только из латинских букв.
   - Ни одна часть домена не пустая и не начинается/не заканчивается дефисом.
   - Домен не начинается и не заканчивается точкой.
4. Общая длина email — не более 254 символов.
