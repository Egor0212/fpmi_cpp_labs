# Лабораторная работа №2. Целочисленная арифметика

Мы продолжаем изучать и работать с базовыми понятиями языка C++: переменные, условия, циклы. В данной лабораторной работе вам предстоит поработать с их более сложным взаимодействием.

Текст с заданием находится в текущей директоии в файле [task_lab2.pdf](./task_lab2.pdf). 

**Номер варианта**: $(N - 1)\mod 14 + 1$, где $N$ – ваш порядковый номер в подгруппе.

> Также в этой лабораторной работе есть дополнительные задачки, в которых вам нужно будет найти "уязвимость" в коде и сделать так, чтобы программа завершилась с ненулевым кодом (т.е. неуспешно). Условие и код для этих задач также находятся в файле lab2_integer_arithmetic.pdf. Советую попробовать их порешать.

Загрузить исходные файлы с решением в ваш репозиторий.
