# Лабораторная работа №5. Строки

В данной лабораторной работе вам предстоит поработать со строками в C++, а точнее с классом `std::string` из стандартной библиотеки (этот класс находится в заголовочном файле `<string>`). Текст задания находится в файле [task_lab5.md](./task_lab5.md).

**Номер варианта**: $(N - 1) \mod 13 + 1$, где $N$ – ваш порядковый номер в подгруппе.

Загрузить исходные файлы с решением в ваш репозиторий.
