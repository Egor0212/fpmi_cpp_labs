# Лабораторная работа №7. Объектно-ориентированное программирование. Класс Vector

Данна лабораторная работа будет поделена на **две части**: написание класса комплексных чисел (Complex) и написание собственного класса-контейнера (Vector).

## Введение в ООП (класс Complex)
Вам разрешено менять только файлы [oop_complex.h](./oop_complex/oop_complex.h) и [oop_complex.cpp](./oop_complex/oop_complex.cpp), в которых будет ваша реализация класса `Complex`. Остальные файлы трогать не нужно, т.к. сборка может сломаться. Тесты к задаче находятся в файле [test.cpp](./oop_complex/test.cpp).

В рамках данной части лабораторной работы вам предстоить написать свой класс, предназначенный для работы с комплексными числами. В классе должны быть:
- Конструктор по умолчанию.
- Конструктор, позволяющий создавать как числа вида $z = a$, так и числа $z = bi$.
- Конструктор копирования.
- Оператор присваивания копированием.
- Операторы сравнения: `==`, `!=`.
- Унарные операторы: `+`, `-`.
- Операторы `+`, `-`, `*`, `\`, позволяющие выполнять арифметические действия как над двумя комплексными числами, так и над комплексным числом и скаляром.
- Операторы `+=`, `-=`, `*=`, `\=`, также позволяющие выполнять арифметические действия как над двумя комплексными числами, так и над комплексным числом и скаляром.
- Операторы ввода/вывода.
- Метод `Real`, который позволяет получить доступ к действительной части комплесного числа.
- Метод `Imag`, который позволяет получить доступ к мнимой части комплесного числа.
- Метод `Abs`, который позволяет получить доступ к модулю комплексного числа.

## Класс Vector
Вам предстоит написать собственный класс `Vector`, который будет являться упрощённым аналогом шаблонного класса `std::vector`. Вам **запрещено использовать стандартные контейнеры и умные указатели**, поэтому _аккуратно работайте с памятью_.

Вам разрешено менять только файлы [vector_impl.h](./vector/vector_impl.h) и [vector_impl.cpp](./vector/vector_impl.cpp), в которых будет ваша реализация класса `Vector`. Остальные файлы трогать не нужно, т.к. сборка может сломаться. Тесты к задаче находятся в файле [test.cpp](./vector/test.cpp).

В классе `Vector` будем хранить элементы типа `int`, а также в нём есть:
- Конструктор по умолчанию.
- Конструктор, принимающий размер вектора и заполняющий его нулями.
- Конструктор, принимающий список инициализции `std::initializer_list<int>` — это позволит создавать вектор следующим образом: `Vector v{1, 2, 3, 4, 5}`.
- Конструктор копирования.
- Оператор присваивания копированием.
- Деструктор.
- Метод `Swap`, который принимает другой вектор по ссылке и меняет содержимое текущего вектора с ним.
- Операторы индексирования: константный и нет. Последний должен позволять менять _содержимое контейнера по индексу_.
- Метод `At`, который работает аналогично оператору индексирования (т.е. у него тоже будет две версии: константная и нет). Отличие этого метода в том, что он проверяет выход за границу массива — в этом случае выбрасывается исключение `std::out_of_range`.
- Метод `Size`, возвращающий число элементов в контейнере.
- Метод `Capacity`, возвращающий текущее число выделенных ячеек памяти под вектор.
- Метод `PushBack`, который добавляет элемент в конец вектора. Если при этом память, которая выделена для вектора, заполнена, то выполните **реаллокацию**: выделите массив вдвое большего размера, скопируйте туда элементы, после чего удалите старый массив. В этом случае `capacity` также должна увеличится вдвое.
- Метод `PopBack`, который удаляет последний элемент вектора. Сужать вектор при этом не нужно, должен измениться только `size`.
- Метод `Clear`, который делает контейнер пустым. Аналогично, сужать вектор при этом не нужно, `size` должен стать нулевым.
- Метод `Reserve`, принимающий новое значение `capacity`, что позволяет зарезервировать место в векторе. Если текущая capacity не мешьне заданного, то метод ничего не должен делать. В ином случае выполните реаллокацию в массив размера `capacity`.
- Оператор вывода. Оператор вывода должен отображать вектор следующим образом:
```cpp
Vector v{1, 2, 3, 4, 5};
std::cout << v; // вывод на консоль [1, 2, 3, 4, 5]
Vector v_empty;
std::cout << v_empty; // вывод на консоль []
```
