# Расчетно-графическая работа №2. STL. Последовательные контейнеры

В этой и последующих задачах мы познакомимся со [стандартной библиотекой](https://en.cppreference.com/w/cpp/standard_library.html) в языке C++ (STL – Standard Template Library).

В рамках данной работы вам предстоит поработать с последовательными контейнерами библиотеки STL: `vector`, `deque`, `array`, `list`, `forward_list`. Другие контейнеры (или адаптеры над контейнерами) использовать **запрещено**!

Текст с заданием находится в файле [task_rgr2.md](./task_rgr2.md).

Загрузить исходные файлы с решением в ваш репозиторий. Текстовые файлы, используемые при решении и тестировании задач также являются исходными (ваши тесты должны быть читабельные, а не абракадабра).
