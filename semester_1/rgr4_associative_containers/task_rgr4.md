# Расчетно-графическая работа №4. STL. Ассоциативные контейнеры

Вам предлагается ознакомиться с двумя сущностями:

1. Структура `Mark`, хранящий информацию о предмете и соответствующей ему оценке (например, за экзамен или зачёт):
    ```cpp
    struct Mark {
        std::string subject_; // предмет
        size_t mark_; // оценка

        // your code goes here
    };
    ```

2. Класс `StudentData`, уже хранящий информацию о результатах сессии конкретного студента:
    ```cpp
    class StudentData {
    private:
        std::string name_; // фамилия, инициалы ("Иванов И.И.")
        size_t number_; // номер зачётки
        std::vector<Mark> marks_; // результаты сессии
        
        // your code goes here
    };
    ```

Требуется реализовать поддержку следующих запросов:
1. Ввести данные из текстового файла `students.txt`. Данные подготовить в виде строк, соответствующих структуре `StudentData`.
2. Отсортировать студентов по номеру зачетки и вывести.
3. Вычислить средний балл по каждому студенту.
4. Вывести список всех студентов в виде `№ п.п., Фамилия, Номер_зачетки, Средний_балл` в алфавитном порядке, для одинаковых фамилий и инициалов — по убыванию среднего балла.
5. Вывести список студентов, средний балл которых принадлежит заданному диапазону. Отсортировать его по убыванию среднего балла.
6. Вывести список студентов, которые сдавали заданный предмет.
7. Определить, сколько студентов сдавало каждый предмет.
8. Для каждого предмета определить средний балл, и вывести предметы и баллы в порядке убывания баллов.
9. Найти всех студентов с максимальной суммой баллов.
10. Найти всех студентов с неудовлетворительными оценками (1, 2, 3).
